Performance history

Median time per operation (per iteration for batched keys) of each benchmark key at each commit of main, oldest to newest. The chart named after a key with "(CPU time)" shows the CPU time of the whole benchmark process per operation, every thread included. The chart named after a key with "(peak RSS)" shows the process's peak resident set size when the key finished. It is a high-water mark, so it covers every key the binary measured before. An orange point ran on a different CPU model than the point before it in the same chart. Each point links to its commit.
